# Zellij: горячие клавиши

В `config.kdl` включено `clear-defaults=true`: это полный набор активных биндов.

## Быстрые команды

| Клавиши | Действие |
|---|---|
| `Alt+t` | Создать таб |
| `Alt+1` … `Alt+9` | Перейти к табу по номеру |
| `Alt+r` | Переименовать активный таб |
| `Alt+←` / `Alt+h` | Фокус влево; на краю — предыдущий таб |
| `Alt+→` / `Alt+l` | Фокус вправо; на краю — следующий таб |
| `Alt+↑` / `Alt+k` | Фокус вверх |
| `Alt+↓` / `Alt+j` | Фокус вниз |
| `Alt+Shift+←` / `Alt+Shift+→` | Переместить текущий таб влево / вправо |
| `Alt+i` / `Alt+o` | Переместить текущий таб влево / вправо |
| `Alt+n` | Создать панель |
| `Alt+f` | Показать / скрыть плавающие панели |
| `Alt+p` | Добавить / убрать панель из группы |
| `Alt+Shift+p` | Включить / выключить режим выбора группы |
| `Alt++`, `Alt+=` / `Alt+-` | Увеличить / уменьшить панель |
| `Alt+[` / `Alt+]` | Предыдущий / следующий layout |
| `Ctrl+p` | Режим управления панелями |
| `Ctrl+t` | Режим управления табами |
| `Ctrl+n` | Режим изменения размера |
| `Ctrl+h` | Режим перемещения панели |
| `Ctrl+s` | Режим скролла |
| `Ctrl+o` | Режим сессии |
| `Ctrl+/` | tmux-режим |
| `Ctrl+g` | Заблокировать бинды |
| `Ctrl+q` | Закрыть Zellij |
| `Esc` | Вернуться в обычный режим |
| `Enter` | Подтвердить действие и вернуться в обычный режим |

## Режим табов — `Ctrl+t`

| Клавиши | Действие |
|---|---|
| `n` | Новый таб |
| `1` … `9` | Перейти к табу и выйти из режима |
| `←` / `↑` / `h` / `k` | Предыдущий таб |
| `→` / `↓` / `j` / `l` | Следующий таб |
| `r` | Переименовать таб |
| `x` | Закрыть таб |
| `s` | Синхронный ввод во всех панелях таба |
| `b` | Вынести текущую панель в новый таб |
| `[` / `]` | Вынести панель в новый таб слева / справа |
| `Tab` | Перейти к предыдущему активному табу |
| `Ctrl+t` | Выйти из tab-режима |

## Режим панелей — `Ctrl+p`

| Клавиши | Действие |
|---|---|
| `←` / `h`, `→` / `l`, `↑` / `k`, `↓` / `j` | Переместить фокус |
| `n` | Создать панель |
| `r` / `d` | Новая панель справа / снизу |
| `s` | Новая панель в стеке |
| `p` | Переключить фокус между панелями |
| `c` | Переименовать панель |
| `e` | Сделать панель плавающей / встроенной |
| `f` | Развернуть / вернуть панель |
| `i` | Закрепить / открепить панель |
| `w` | Показать / скрыть плавающие панели |
| `z` | Показать / скрыть рамки |
| `x` | Закрыть активную панель |
| `Ctrl+p` | Выйти из pane-режима |

## Размер и перемещение панели

| Режим | Клавиши | Действие |
|---|---|---|
| `Ctrl+n` | `h/j/k/l` или стрелки | Увеличить панель в указанную сторону |
| `Ctrl+n` | `H/J/K/L` | Уменьшить панель в указанную сторону |
| `Ctrl+n` | `+`, `=` / `-` | Увеличить / уменьшить со всех сторон |
| `Ctrl+h` | `h/j/k/l` или стрелки | Передвинуть панель |
| `Ctrl+h` | `n`, `Tab` | Передвинуть панель вперёд по позициям |
| `Ctrl+h` | `p` | Передвинуть панель назад по позициям |

## Скролл и поиск

| Клавиши | Действие |
|---|---|
| `Ctrl+s` | Войти / выйти из скролла |
| В скролле: `j/k`, `↓/↑` | Прокрутка вниз / вверх |
| В скролле: `h/l`, `←/→`, `PageUp/PageDown`, `Ctrl+/`, `Ctrl+f` | Страница назад / вперёд |
| В скролле: `u` / `d` | Полстраницы вверх / вниз |
| В скролле: `Ctrl+c` | Вниз к текущему выводу и выход |
| В скролле: `s` | Начать поиск |
| В скролле: `e` | Открыть scrollback в редакторе |
| В поиске: `n` / `p` | Следующее / предыдущее совпадение |
| В поиске: `c` | Регистр букв |
| В поиске: `w` | Зацикливание поиска |
| В поиске: `o` | Поиск целых слов |

## Сессии и tmux-режим

| Режим | Клавиши | Действие |
|---|---|---|
| `Ctrl+o` | `a` | Окно «About» |
| `Ctrl+o` | `c` | Настройки Zellij |
| `Ctrl+o` | `p` | Менеджер плагинов |
| `Ctrl+o` | `s` | Поделиться сессией |
| `Ctrl+o` | `w` | Менеджер сессий |
| `Ctrl+o` или tmux-режим | `d` | Отсоединиться от сессии |
| `Ctrl+/` | `c` | Новый таб |
| `Ctrl+/` | `n` / `p` | Следующий / предыдущий таб |
| `Ctrl+/` | `h/j/k/l` или стрелки | Фокус между панелями и выход |
| `Ctrl+/` | `"` / `%` | Панель снизу / справа |
| `Ctrl+/` | `,` | Переименовать таб |
| `Ctrl+/` | `[` | Скролл |
| `Ctrl+/` | `z` | Развернуть панель |
| `Ctrl+/` | `?` | Окно со справкой биндов |

В режиме блокировки `Ctrl+g` снова разблокирует бинды.
